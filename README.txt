# Texas Sales Analysis

## Project Description

Analyze sales data in the state of Texas to identify sales trends, compare performance accross stores, and examine different product categories. 

### Project Objectives

- Analyze Texas sales.
- Identify monthly and yearly trends.
- Compare stores across the whole region.
- Find growth areas to focus on. 

## Tools

I will be using MySQL and Excel to analyze data and create charts that visually describe my findings. 

- MySQL
- Microsoft Excel
- GitHub

### Dataset

The dataset contains records from multiple stores accross the United States starting from the first day of 2022 throughout the end of 2025 with information on different products, transactions, and store information.

### Assigned territory

Texas
